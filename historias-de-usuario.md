
# HISTORIAS DE USUARIO

## 👤 Usuario: Administrador (Dueño/Emprendedor)
- Gestionar productos con fotos, descripciones y categorías para mantener actualizado el catálogo.
- Definir precios minoristas y mayoristas para adaptarme a distintos tipos de clientes.
- Reservar stock cuando se genera un pedido para evitar vender productos no disponibles. Y actualizarlo cuando se confirme o cancele un pedido.
- Configurar los datos de mi tienda (nombre, logo y WhatsApp).
- Generar un enlace público de catálogo para compartirlo en redes sociales.
- Registrar pedidos manualmente para ventas realizadas fuera del sistema.
- Validar el stock al crear pedidos para evitar vender productos no disponibles.
- Visualizar reportes de ventas y ganancias para analizar el rendimiento del negocio.
- Consultar el historial de pedidos por cliente para entender su comportamiento de compra.
- Gestionar el estado de los pedidos (Pendiente, En Preparación, Enviado, Entregado).
- Organizar pedidos por zona para optimizar las entregas.
- Asignar pedidos a repartidores o servicios de envío para gestionar la logística.
- Calcular automáticamente el total del pedido aplicando descuentos para ventas mayoristas.


## 🌐 Usuario: Cliente
- Ver el catálogo con productos y precios.
- Armar un pedido y enviarlo por WhatsApp para concretar la compra fácilmente.
- Seleccionar el método de entrega para recibir mi pedido según mi conveniencia.
- Consultar el estado de mi pedido para saber en qué etapa se encuentra.
